# Mon atelier

Prisme est maintenant développé en C11 avec raylib.
Python 3 n'est utilisé que pour exécuter les scripts de cet atelier.

- main.py : un premier programme, à lancer avec F5.
- couleurs.py : un module local importé par main.py.

Ctrl+N : nouveau · Ctrl+S : enregistrer · Ctrl+F : rechercher.
Ctrl+P : fichiers · Ctrl+Maj+P : commandes · F6 : effets.

La démo visuelle 100 % C se trouve dans demos/constellation.c.
Elle se compile avec le projet et se lance avec bin/constellation.
